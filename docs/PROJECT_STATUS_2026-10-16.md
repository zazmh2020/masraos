## حجم المشروع اليوم

- 98 صفحة و111 واجهة برمجية (API).
- 42 جدولًا في قاعدة البيانات و23 ترحيلًا (migration).
- 189 اختبارًا آليًا ناجحًا في 26 ملفًا، وفحص شيفرة وبناء إنتاج ناجحان.
- فحص جودة آلي على GitHub (اختبارات + فحص + بناء) مع كل تحديث.
- التقنيات: Next.js 16.3.8، React 19.2.8، Prisma 7.9.1، PostgreSQL.

## ما أُنجز في هذه الجلسة

- دمج نسخة Codex المحسّنة: مصدر هوية موحد، شعار متجه، إصلاحات خصوصية الإشعارات والمسودات، سجل الطالب الزمني، تحسينات الجوال والتنقل.
- تحديث الحزم إلى Next.js 16.3.8، وحزمة أدوات التطوير (مهارات، فحص جودة آلي، Dependabot، Playwright).
- الشعار الرسمي في رأس الموقع والتذييل والدخول والتسجيل ونافذة اللغة، باتجاه يتبع اللغة.
- الافتتاحية المتحركة بالشعار الرسمي (أفقي للكمبيوتر، عمودي للجوال)، مرة لكل جلسة.
- رأس الجوال: الشعار في المنتصف، القائمة في البداية واللغة في الجهة المقابلة، والعملة داخل القائمة.
- حذف أزرار الحسابات التجريبية من صفحة الدخول.

## خطة الإكمال المقترحة (بالأولوية)

### المرحلة 1 — عوائق الإطلاق (الأولوية القصوى)

1. **حزمة الأمان الأولى:** ترويسات الأمان، حد محاولات الدخول، توحيد زمن الدخول، تقييد الملفات المرفوعة، فحص بقية مسارات العزل مع اختبارات.
2. **استعادة كلمة المرور** وربط **مزود بريد فعلي** (Resend جاهز للربط) لرموز التحقق.
3. **النسخ الاحتياطي** لقاعدة الإنتاج وتجربة استعادة واحدة على الأقل.
4. **بيئة تجريبية (Staging)** قبل كل نشر على masraos.com.
5. **مراجعة المحتوى**: لا شهادات أو أرقام غير حقيقية، ومراجعة قانونية لنصوص الخصوصية والشروط.

### المرحلة 2 — التشغيل التجاري

1. **قرار الأسعار** ثم تفعيل الدفع في وضع الاختبار، ثم حيًا بعد موافقتك.
2. اعتماد تصميم لوحة المركز الجديد ونطاق رؤية المعلم.
3. اختبارات متصفح للرحلات الأساسية: تسجيل مركز، إضافة طالب، حضور، حفظ، رسوم، تقرير ولي أمر.
4. نشر آلي من GitHub ومراقبة الأخطاء.

### المرحلة 3 — التميّز

1. التجارب المميزة: رحلة الطالب، مقياس الإتقان، صحة الحلقة (تحتاج تعريفات منك).
2. الوضع الداكن، قياس الأداء وتحسينه، تطبيق الجوال (PWA) كامل.
3. قوالب أكثر للمواقع العامة للمؤسسات، والطباعة والشهادات بالهوية الجديدة.
