# تشغيل مَسرى محليًا للمراجعة والتطوير

## التشغيل

- افتح `Start-MASRA.cmd` من مجلد المشروع، وانتظر ظهور Ready.
- افتح `http://localhost:3000/login`.
- أبقِ نافذة التشغيل مفتوحة. لا تشغّل نسخة ثانية إذا كان الموقع يعمل بالفعل.
- ملف `Backup-MASRA.cmd` ينشئ نسخة احتياطية محلية في `.local/backups`؛ انسخ النسخ المهمة إلى وسيط آخر آمن.
- من الطرفية: `npm run dev:local`، والنسخ `npm run local:backup`.
- لإيقاف قاعدة البيانات بعد إغلاق الموقع: `npm run local:stop-db`.

## ما الذي تغير؟

- PostgreSQL 17 محمول داخل `.local/pgsql`، وقاعدة مستقلة `masra_local_dev` على `127.0.0.1:5433` فقط.
- البيانات المستمرة داخل `.local/pgdata`؛ لا تحذف مجلد `.local` لأنه يحتوي قاعدة بياناتك والنسخ الاحتياطية.
- الموقع يستمع على `127.0.0.1:3000` فقط؛ لا يتاح لأجهزة أخرى تلقائيًا.
- `.env.local` يضبط الاتصال المحلي وسر جلسات منفصلًا. ملف `.env` القديم لم يستبدل، وقاعدة البيانات السحابية لم تعدل.
- `.env.local` و`.local` مستبعدان من Git. الملفات المحلية تحتوي بيانات حساسة، فلا ترسلها أو تنشرها.
- البيانات الحالية وهمية: 15 طالبًا وحلقتان و5 أيام حضور، وليست نقلًا لبيانات Neon. نقل البيانات الأصلية يحتاج اتصالًا صالحًا بالمصدر أو نسخة احتياطية منه.
- إعدادات الدفع والبريد والمساعد والتبليغ الخارجي معطلة في البيئة المحلية لمنع أي اتصالات أو رسوم غير مقصودة.
- الصور والوثائق تحتاج تخزينًا خاصًا مُعدًا؛ لا يوفر PostgreSQL وحده تخزين S3. تبقى الاستمارة قابلة للاستخدام دون صورة.
- القاعدة تعمل دون اشتراك، لكنها تحتاج تشغيل الجهاز والنسخ الاحتياطي. ليست بيئة إنتاج أو استضافة عامة.

## الإعداد والصيانة

- `npm run local:setup` يبدأ القاعدة، وينشئ قاعدة التطوير عند عدم وجودها، ويطبق الهجرات ويولّد Prisma ويضيف بيانات الاختبار المفقودة فقط.
- التهيئة لا تعيد ضبط القاعدة ولا تحذف البيانات. الحسابات/الطلاب الموجودون لا تُستبدل تعديلاتهم.
- سكربت التشغيل يرفض العمل على قاعدة غير `masra_local_dev` في `127.0.0.1:5433`.
- PostgreSQL مأخوذ من حزمة Windows المرتبطة بصفحة PostgreSQL الرسمية عبر EDB. لا توجد خدمة Windows أو قواعد جدار ناري جديدة.
- للعودة إلى البيئة السابقة لا تحذف البيانات المحلية؛ أوقف الموقع أولًا ثم راجع ترتيب إعدادات البيئة. يجب أن يكون اتصال المصدر صالحًا قبل الاعتماد عليه.
