# تفعيل بريد التحقق — Resend

تم تجهيز الربط فقط؛ لم يتم إنشاء حساب مزود أو تغيير DNS أو إرسال رسالة فعلية أو نشر التعديلات.

1. أنشئ حساب Resend تحت ملكيتك وأضف نطاق إرسال تملكه. أضف سجلات DNS التي يوفرها المزود حرفيًا وانتظر التوثيق. لا تحذف سجلات البريد القائمة.
2. أنشئ مفتاح API بصلاحية الإرسال اللازمة فقط، ثم خزنه في أسرار الاستضافة أو .env.local محليًا. لا تضعه في المحادثة أو Git أو متغير NEXT_PUBLIC.
3. اضبط RESEND_API_KEY، وEMAIL_FROM بعنوان من النطاق الموثق، وOTP_EMAIL_PROVIDER=resend.
4. أعد تشغيل التطبيق بعد تغيير البيئة. اختيار resend صريح ولا يتحول إلى webhook أو رمز تطوير عند فشل الإرسال.
5. اختبر إنشاء حساب ببريد تملكه في Staging: وصول الرسالة، الرمز الصحيح والخاطئ والمنتهي وإعادة الإرسال. نجاح API يعني قبول الرسالة لدى المزود وليس إثبات وصولها لصندوق الوارد.

قالب الرسالة عربي RTL مع نسخة نصية. مهلة الاتصال 8 ثوانٍ، ولا يُقبل رد نجاح بلا معرف رسالة. لا تُسجل الرموز أو تفاصيل أخطاء المزود للمستخدم.

هذه الخدمة للبريد فقط. الرسائل الهاتفية تبقى عبر مزود مستقل؛ تهيئة Resend لا تفعّل SMS أو WhatsApp. لا تُفعّل التسجيل العام قبل معالجة مراجعة التزامن وحدود الإساءة الواردة في تقرير المخطط.

مرجع الربط: https://resend.com/docs/api-reference/emails/send-email
