## التشغيل

شغّل `npm run dev:preview` من هذا المجلد، أو ملف `Start-MASRA-Local.cmd` الموجود في مخرجات المحادثة. أبقِ عملية الموقع قيد التشغيل. يتأكد المشغّل من بيئة قاعدة البيانات ويعيد استخدام الموقع إذا كان يعمل بالفعل.

يتطلب تشغيل النسخة إعداد `.env.local` الخاص الموجود حاليًا، وتوزيع WSL الحالي MASRA-Dev وPostgreSQL 17 على المنفذ 5433. المشغّل يرفض أي قاعدة غير `masra_preview_20261013` بالمستخدم `masra_preview` على الاتصال المحلي. لا تنقل ملف البيئة إلى مستودع أو خدمة نشر.

الحسابات الموجودة بيانات اختبار محلية. كلمة المرور المشتركة للاختبار فقط: `MasraLocal2026!`.

| الحساب | البريد |
|---|---|
| مدير المركز | admin@masra.local |
| مالك المنصة | owner@masra.local |
| المعلم | teacher@masra.local |
| ولي الأمر | guardian@masra.local |

روابط الدخول السريع تظهر في بيئة التطوير. منفذ dev-login يرفض بيئة الإنتاج بالكامل حتى مع ENABLE_DEMO_LOGIN=1. اعتمد المستخدم هذا التعديل مع إصلاح تزامن التحقق وإعادة إرسال الرمز.

## استقلال البيانات

نسخة المصدر الأصلية في الأرشيف لم تُعدّل. قاعدة `masra_local_dev` لم تُعدّل. نُسخت البيانات المحلية الحالية إلى قاعدة جديدة، ثم طُبّقت عليها فقط الهجرات الثلاث الموجودة بالفعل لإنشاء طلبات التسجيل وإصدار الجلسات ونمط واجهة المؤسسة. لم تُنشأ هجرات جديدة.

نسخة المصدر المضغوطة المرفقة مع التقرير لا تحتوي الحزم المثبتة أو أسرار البيئة أو قاعدة البيانات أو ملفات Git. ليست نسخة احتياطية للبيانات.

## النشر لاحقًا

1. افصل بيانات الاختبار وحساباته عن بيئة الإنتاج.
2. وفّر إعداد قاعدة إنتاج ومزود تحقق ونسخة بيانات قابلة للاستعادة.
3. راجع خطة الأمان والأسعار والأصول الأصلية في تقرير التنفيذ.
4. ثبّت الحزم من `package-lock.json`؛ ثم ولّد Prisma وشغّل الاختبارات وبناء الإنتاج.
5. راجع الهجرات والنسخ الاحتياطية في بيئة اختبار قبل أي تفعيل.
6. لا يوجد نشر خارجي ضمن هذه المهمة المحلية.
